**Auto Draft 1.1.0**: help and support, built in.

- **Help** (the **?** on the top bar, or **F1**): What's new, the user guide, the keyboard shortcuts,
  **Report a problem** (the contact form opens with the program and version filled in), the error
  log and the open-source licences.
- **A clear message when something goes wrong.** An unexpected error shows a short notice with
  **Report a problem**, instead of a grey screen, and is written to an error log next to the
  program, to attach when you write to us.
- **A start screen** with the icon and name shows the moment you open it.
- **Signed in already.** Opened from a desktop shortcut or the Start menu, it signs in with the
  Survey Toolkit's account on this PC, if there is one.
- The publisher in Windows' list of programs is now **SurveyX Digital**.

Nothing changes in how your drawings are made: codes, symbols, contours, DXF, PDF and KML work as
in 1.0.3, and your code lists and sheet settings are kept.

Auto Draft updates itself: open it while you're online. New to it? Download `AutoDraft-Setup.exe`
from [exceltokml.com/auto-draft](https://www.exceltokml.com/auto-draft). If Windows says it protected your PC, choose **More info**, then **Run anyway** (the programs are not signed with a paid certificate yet).
