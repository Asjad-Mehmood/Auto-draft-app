**Auto Draft 1.0.1**: a small update to 1.0.0.

- The version number shown in Auto Draft and in Windows' list of programs is now right everywhere.
- Nothing changes in how your drawings are made: codes, symbols, contours, DXF, PDF and KML work
  as in 1.0.0, and your code lists and sheet settings are kept.

Auto Draft updates itself: open it while you're online. New to it? Download `AutoDraft-Setup.exe`
from [exceltokml.com/auto-draft](https://www.exceltokml.com/auto-draft) and see the
[field code guide](https://www.exceltokml.com/auto-draft/codes). If Windows says it protected your PC,
choose **More info**, then **Run anyway**.
